# RagRevival 1.3.6

Install `ragrevival-1.21.1-1.3.6.jar` on the server and every client,
replacing the previous RagRevival JAR while the instances are stopped.
Source and SHA-256 checksums are alongside it.

- Drag downed players while standing or crouching: empty both hands, aim at
  the body, and hold Use/right-click. Releasing Use drops the body.
- Feed teammates while standing or crouching: hold Use with a golden apple
  or golden carrot. Changing posture no longer cancels feeding.
- Prompts show the configured Use key and a short hold instruction.

Feeding duration, server reach checks, exclusive rescue ownership, Carry On
exclusion, self-revival, bleed-out pauses, and Unlocked Camera zoom handling
are unchanged. Dependencies are not bundled. Minecraft 1.21.1, Java 21,
NeoForge, Sable, Sable: Ragdolls 0.7.2, and Ragdoll Reactions 0.7.0 are required.

See [verification notes](../../docs/test-results-1.3.6.md) for the checks run
on this build and the remaining two-player manual checks.
