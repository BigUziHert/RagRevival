# RagRevival 1.0.0

- Install `ragrevival-1.21.1-1.0.0.jar` in the server and both clients.
- `ragrevival-1.21.1-1.0.0-sources.jar` is the matching mod source archive; the repository also includes build scripts and test sources.
- SHA-256 digests are in `SHA256SUMS`.

Requires Java 21, Minecraft 1.21.1, NeoForge 21.1.249+, Sable 2.0.3, Sable Ragdolls 0.7.2, and Ragdoll Reactions 0.7.0. The three mod versions are deliberately pinned to the inspected and tested APIs. Dependencies are separate downloads; this release does not bundle them or the test harness.

See the repository [README](../../README.md) for installation, controls, server configuration, lifecycle behavior, and the two-player checklist. [Verification evidence](../../docs/test-results.md) distinguishes automated tests from remaining visual/input checks.
