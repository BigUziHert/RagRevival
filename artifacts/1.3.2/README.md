# RagRevival 1.3.2

Install `ragrevival-1.21.1-1.3.2.jar`, replacing the previous RagRevival JAR
on the server and clients. Source and SHA-256 checksums are alongside it.
Network protocol 3 is unchanged.

The give-up prompt stays **Hold for 5s to give up** in the same color while
G is held. The card's green progress track, five-second hold, and release
cancellation are unchanged.

**Assembled only; no tests were run at the user's request.** The
[1.3.1 verification report](../../docs/test-results-1.3.1.md) records the
previous tested release, not new results for 1.3.2.

Requires Java 21 / Minecraft 1.21.1 / NeoForge 21.1.249 and pinned Sable 2.0.3,
Sable Ragdolls 0.7.2, and Ragdoll Reactions 0.7.0. Dependencies and the test
harness are not bundled. See the [README](../../README.md).
